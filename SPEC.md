# threads-video-studio — implementation spec (internal contract)

This file is the contract between the skills (instructions for Claude) and the scripts.
Keep it in sync when a script's interface changes.

## Goal
Make short vertical (9:16) AI videos for Threads in an anime/illustration style, with Japanese
narration, captions, BGM and a call-to-action, then schedule and auto-post them to Threads and
review results. Human approval gates are mandatory before paid generation and before posting.

## Runtime
- Python 3.10+, **standard library only** (optional: `pyopenjtalk` for `yomi_check.py`).
- `ffmpeg` / `ffprobe` on PATH. `npx` (Node 18+) for HyperFrames rendering. `aws` CLI only if S3 staging is used.
- Every script: `python3 <plugin>/scripts/<name>.py --help` works, exits non-zero with a one-line
  reason on failure, never prints secrets, and is safe to re-run (idempotent or resumable).
- Settings come from `scripts/common.py` (`common.get(key)` / `common.require(key)`). Never read
  keys any other way. Keys: see `SETTINGS` in common.py.

## Project folder (one video = one folder)
`<workspace>/<slug>/` (workspace default `~/threads-videos`, slug like `t004-camp`; slugs and cut ids match `^[A-Za-z0-9_-]{1,64}$`)
```
brief.md                 # thesis, audience, type (story|intro), target length
shots.json               # SINGLE SOURCE OF TRUTH for cuts (see schema)
storyboard/              # rough frames c01.png ... (any generator), index.html for review
character/               # sheet.png (character sheet), refs/*.png
frames/                  # final start frames c01.png ... (clean, no text/bubbles), c01-end.png optional
clips/                   # generated clips c01.mp4 + c01.json (request id, model, prompt, cost)
                         #   c01-draft.mp4 = draft (cheap) result, never overwrites the final clip
                         #   c01.task = pending request id (resume)
voice/                   # script.txt, yomi.json, all.mp3, align.json, lines.json
bgm/                     # bgm.mp3 (chosen), candidates/
qa/                      # contact sheets, qa.json
video/                   # HyperFrames project (generated by assemble.py)
final/                   # <slug>-final.mp4 (1080x1920), <slug>-post.mp4 (compressed for upload)
post.json                # posting draft (see threads)
```

## shots.json schema
```json
{
  "slug": "t004-camp",
  "type": "story",                 // story (10-15s, ~3 cuts) | intro (20-30s)
  "fps": 24,
  "cta": {"label": "LINEで話してみる", "sub": "プロフィールのリンクから", "show": true},
  "cuts": [
    {
      "id": "c01",
      "line": "友達5人で、海辺のキャンプへ！",       // narration line (also caption source)
      "caption": ["友達5人で、", "[[海辺のキャンプ]]へ！"], // optional manual caption lines; [[ ]] = highlight 1 word
      "action": "walk into the field",          // ONE subject action
      "camera": "slow tracking forward",         // ONE camera move
      "prompt": "...",                           // video prompt (written by Claude, approved by human)
      "model": "seedance20",                     // see gen_video MODELS
      "frame": "frames/c01.png",
      "end_frame": null,                         // optional last frame (first-last mode)
      "refs": [],                                // optional reference images (reference mode)
      "start": 0.0, "dur": 3.2                   // filled by timing (voice) step
    }
  ]
}
```

## Scripts (CLI contracts)
All paths may be absolute or relative to the project folder given by `--project`.

| script | purpose | key args | outputs |
|---|---|---|---|
| `setup.py` | show/set settings | `status` / `set <key>` (hidden prompt) / `path` / `import <json>` | config file (0600) |
| `new_project.py` | create project skeleton | `<slug> --type story|intro` | folder + brief.md + shots.json |
| `gen_image.py` | text-to-image / edit (frames, character sheet, fixes) | `--prompt`, `--image` (repeatable refs), `--model seedream45|nano-banana-pro`, `--out`, `--size 1440x2560` | png + `.json` sidecar |
| `gen_video.py` | image-to-video per cut, resumable | `--project`, `--cut c01` or `--all`, `--draft` (cheap/fast 480p), `--model`, `--dry-run` (cost estimate only) | `clips/<cut>.mp4/.json`, `.task` while pending |
| `yomi_check.py` | pre-generation reading check | `--project` (reads voice/script.txt) | report + `voice/yomi.json` suggestions |
| `gen_voice.py` | ONE-PASS ElevenLabs v3 narration with timestamps | `--project`, `--voice-id`, `--tag "[cheerfully]"` | all.mp3, align.json, lines.json (start/end per line), writes cut start/dur into shots.json |
| `gen_bgm.py` | instrumental BGM | `--project`, `--prompt`, `--seconds`, `--provider elevenlabs|fal` | bgm/candidates/*.mp3 |
| `qa_frames.py` | QA contact sheets + numeric checks | `--project`, `--cut` or `--final`, `--fps 4` | qa/*.jpg, qa/qa.json (freeze spans, motion score, seam diffs) |
| `assemble.py` | build HyperFrames project from shots.json + voice + bgm, render | `--project`, `--render` | video/, final/<slug>-final.mp4, final/<slug>-post.mp4 |
| `threads_post.py` | posting queue + publish | `draft` / `approve --by <name>` / `schedule --at "YYYY-MM-DD HH:MM"` / `publish-due [--dry-run] [--max N]` / `status` / `mark-published <slug> --post-id` / `refresh-token` (all accept `--workspace`) | `<workspace>/posts.json` queue |
| `threads_insights.py` | pull metrics, write learnings | `pull` / `review` | `<workspace>/learnings.csv`, `<workspace>/reports/YYYY-MM-DD.md` |

| `threads_api.py` | shared Threads Graph client, token refresh, atomic writes, file lock (library) | — | — |

### Rules baked into scripts
- gen_video: save request id to `clips/<cut>.task` immediately after submit; resume on re-run; poll with
  retry on network errors; on success remove `.task`. Never silently drop unsupported params: validate per model
  (duration enum, resolution enum) and fail with "Allowed: ...". `--dry-run` prints cost estimate.
- gen_voice: reads voice/script.txt (falls back to shots.json `line` when empty); `--retime` recomputes
  timing from an existing align.json without calling the API. Whole script in one request (`/v1/text-to-speech/{voice}/with-timestamps`, model `eleven_v3`,
  `language_code=ja`), single leading emotion tag; spoken text applies `voice/yomi.json` replacements but captions
  keep the original text.
- qa_frames: contact sheet at 4 fps for clips, 2 fps for final; `freezedetect` spans > 0.4s are flagged
  (frozen picture looks dead); report max frame diff at cut seams.
- threads_post: an approval stores a hash of text/video/topic; if any changes after approval, publishing stops until re-approved.
- threads_post: publish only items with status=approved AND approved_by non-empty AND scheduled_at <= now AND
  no published_id. Mark `publishing` before calling the API; never auto-retry an item left in `publishing`.
  Media: `media_url` if given, else stage `video_file` via media_host (S3). Topic tag supported (`topic`).
