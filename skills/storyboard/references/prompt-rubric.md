# 動画プロンプトの自己採点表

承認（G1）に出す前に、カットごとに採点する。**必須（M）に1つでも×があれば直す。** 推奨（R）は2つまで×を許す。

| # | 区分 | 観点 | ○の条件 |
|---|---|---|---|
| M1 | 必須 | 動作は1つか | 主語の動詞が1つ。「歩いて、振り向いて、手を振る」のように重ねていない |
| M2 | 必須 | カメラは1つか | push-in / tracking / static / tilt のどれか1つ |
| M3 | 必須 | 人数 | 動く人物は1〜2人。群衆は背景として静かにさせる |
| M4 | 必須 | 手の中の物 | 持ち物は形の単純なもの。刃物・細い道具・小さな文字の物を持たせていない |
| M5 | 必須 | 起点画像との一致 | 画風・顔・服・持ち物を「起点画像のまま保つ」と書いている |
| M6 | 必須 | 文字を出さない | no text / no speech bubbles / no logos がある。起点画像にも文字・吹き出しが無い |
| M7 | 必須 | 尺 | カットの尺がナレの長さ＋0.3秒以上あり、モデルの許容秒数に収まる |
| M8 | 必須 | 権利と人物 | 実在の顔・名前・ロゴ・第三者の画面が入っていない。人物はアニメ調・イラスト調 |
| R1 | 推奨 | 動きの大きさ | 動作が画面で見て分かる大きさ（小さすぎる動きは「止まって見える」） |
| R2 | 推奨 | 主役が画面に残る | カメラの移動で主役が画面の外に出ない |
| R3 | 推奨 | 光と空気 | 時間帯・光の向き・空気感が1語以上ある |
| R4 | 推奨 | 感情 | そのカットで見る人に起こしたい気持ちが、動作か表情で表れている |
| R5 | 推奨 | つながり | 前後のカットと、向き・明るさ・持ち物が矛盾しない |

採点結果は、承認パケットに「カットごとに M ×の数／R ×の数」として載せる。
