# narration — 読みの確認・通し生成・尺の確定


## 1. 原稿
- 1秒あたり5〜6字。速度を上げて詰め込まない（詰まって聞こえる）。足りなければ原稿を削る。
- 字幕と同じ字面にする（読みの補正は辞書で行い、原稿の字面は変えない）。

## 2. 読みの事前チェック（生成の前に必ず）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/yomi_check.py --project <dir>            # 各行の読みと要注意語の一覧
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/yomi_check.py --project <dir> --suggest  # 読み替え候補を voice/yomi.json に追記
```
- 英字・数字・記号・読みが複数ある漢字（例：創る、生、上手、方）を確認する。
- 直したい読みは `voice/yomi.json` に `{"表記": "よみ"}` で入れる（例：`{"創る": "つくる", "AI": "エーアイ"}`）。発話にだけ使われ、字幕は元の字面のまま。
- 通しで1回生成するので、1か所読み間違えると全部作り直しになる。ここで拾うのが一番安い。

## 3. 声の選び方
- ElevenLabs のライブラリから、**日本語ネイティブの声**を選ぶ（英語ベースの声は日本語が不自然）。
- 物語系は語り手の声、キャラの紹介系はキャラの声。シリーズで声を固定する（設定 `narrator_voice_id`）。
- ナレーターとキャラが両方話すなら、声を2つ決める（4-1）。

## 4. 通しで1回生成（声色をそろえる）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/gen_voice.py --project <dir> --voice-id <id> --tag "[cheerfully]"
```
- 全行を1回のリクエストで生成し、感情タグは冒頭の1つだけ。**行ごとに別々に作らない**（声色がばらつく）。
- 出力：`voice/all.mp3`、文字ごとの時刻 `align.json`、各行の開始・終了 `lines.json`。
- `shots.json` の各カットの `start`・`dur` が自動で入る（次の行の開始の0.15秒前で切り替え、最後は +1.0秒）。

## 4-1. ナレーターとキャラが交互に話すとき（話す人が2人以上）
ナレーションの途中でキャラ（AI のキャラなど）がセリフを言う動画では、**話す人ごとに声を決め、カットが変わっても同じ人は同じ声にする**。全部を1つの声で読ませると、キャラのセリフがナレーションに埋もれて「セリフが消えた」ように聞こえる。
1. `shots.json` に話す人と声を書き、各カットに `speaker` を付ける（無いカットは `narrator`）。
   ```json
   "speakers": {
     "narrator": {"voice_id": "<ナレーターの声>", "tag": "[excited]"},
     "ai":       {"voice_id": "<キャラの声>",     "tag": "[cheerfully]"}
   },
   "cuts": [
     {"id": "c01", "line": "朝5時。畑はAIが耕す", ...},
     {"id": "c03", "speaker": "ai", "pause_before": 1.6, "line": "社長、来年もナスにします？", ...}
   ]
   ```
   - `pause_before`：そのセリフの前に置く間（秒）。キャラが画面に現れてから話させたいときに使う（例：スマホから飛び出すまで待つ）。カットはその分だけ前から始まる。
   - 字幕でも誰が話しているか分かるように、キャラのセリフは `caption` を「AI「…」」のように書く。
2. 同じコマンドで作る。**同じ人のセリフは1回のリクエストでまとめて作る**ので、カットをまたいでも声色がそろう。
   ```bash
   python3 ${CLAUDE_PLUGIN_ROOT}/scripts/gen_voice.py --project <dir> --dry-run   # 話す人ごとの文と字数
   python3 ${CLAUDE_PLUGIN_ROOT}/scripts/gen_voice.py --project <dir>             # 生成→切り出し→カット順に並べる
   ```
   - 出力：話す人ごとの `voice/<speaker>.mp3`・`align-<speaker>.json`、並べ直した `voice/all.mp3`・`lines.json`（行ごとに `speaker` 付き）、各カットの `start`・`dur`。
   - 同じ文・同じ声なら作り直さない（`pause_before` だけ変えたときは費用がかからない）。作り直すときは `--force`。
3. 聞いて、**キャラのセリフがキャラの声で入っているか**を確かめる。声の性質（高さ・年齢・温度）がナレーターと離れている方が聞き分けやすい。キャラの声はシリーズで固定し、`world.md` に書いておく。
4. 読みは話す人に関係なく `voice/yomi.json` で直す（例：`{"農家": "のうか"}`。声によって読み間違える語が違う）。

## 4-2. 世界観の音を入れるとき（演技の指示・本人の声）
- `world.md` に演技の指示（冒頭・中盤・終盤）があれば、声選びと冒頭の感情タグに反映する。
- **今の `gen_voice.py` で付けられる感情タグは、話す人ごとに冒頭の1つだけ**（4-1 の `speakers` の `tag`）。 原稿の行の途中にタグや記号を入れない（字幕にそのまま出て、尺の計算もずれる）。場面ごとに演技を変えたいときは、間は原稿の句読点と行の区切りで作り、それでも足りなければ本人に「今の仕組みでは場面ごとのタグは入れられない」と伝えてから決める。
- 本人の声を使う場合は、録音を `voice/all.mp3` に置く。文字ごとの時刻が無いので、行ごとの時刻を聞いて `voice/lines.json`（`[{"cut": "c01", "start": 0.2, "end": 3.1}, ...]`）に書き、カットの `start`・`dur` も合わせて入れる（無いと BGM がナレの間に下がらない）。ずれはキューシート（`cuesheet.py --check`）で確かめる。

## 5. 聞いて確認
- 通しで聞き、読み間違い・不自然な間・詰まりがあれば、辞書か原稿を直して**全体を作り直す**（数円〜数十円）。
- 合格したら、カットの尺が決まる。動画の生成はこのあと（尺が決まってから）。
